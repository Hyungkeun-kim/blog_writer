# Security & PII Auditor Role Guide

## 역할 개요
- CR-2 직접 식별정보 탐지 규칙, Cloudflare 이미지 처리 경계, 원본/중간 산출물 수명주기 및 비밀키 노출 방지를 검증합니다.

## 핵심 점검 항목
- [ ] 사진의 Workers AI 처리가 명시되고 탐지를 위해 별도 외부 서비스에 원문을 추가 전송하지 않는가?
- [ ] 직접 식별정보 탐지 시 후속 호출·본문 노출이 차단되고 R2 이미지 및 중간 데이터가 삭제되는가?
- [ ] 저장·Vision 호출 전에 사용자 파일명과 EXIF/GPS가 제거되는가?
- [ ] 사용자 작업 종료·실패·취소 시 삭제가 시작되고 모든 임시 데이터가 24시간 상한을 지키는가?
- [ ] Cloudflare 서비스 자격 증명이 브라우저나 클라이언트에 노출되지 않는가?
